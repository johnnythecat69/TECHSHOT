# Сердце чащи

Одиночная 3D-веб-игра о проклятой доске. Партия проходит по 32 клеткам. Бросок запускает события, обряды на память, сделки, привалы и тайники. Для победы собери три печати и пройди финальный обряд. После победы или поражения можно снова отправить того же персонажа в чащу.

## Запуск

Нужен Node.js 24 или новее.

```sh
npm ci
npm test
npm run dev
```

Открой http://127.0.0.1:4173. Для локального запуска есть регистрация с логином и паролем. Персонаж и партия сохраняются в `.data/thorn-heart.sqlite`. Локальный сервер слушает loopback по умолчанию и предназначен для разработки на своей машине.

## Управление

- Перетащи доску для поворота. Колесо мыши приближает сцену. Кнопка «Вид сверху» переключает камеру.
- После запоминания рун нажимай их на 3D-доске, под ней или клавишами 1–5.
- Талисман даёт бросок от 1 до 3. Шестёрка добавляет руну в следующий обряд.
- Один персонаж на аккаунт. Доступны три класса и четыре расцветки фигурки.

## Устройство

- `src/scene.js` собирает сцену процедурно на [Three.js](https://github.com/mrdoob/three.js) (MIT). Уровень, материалы, иконки и синтезируемые звуки созданы для этой игры.
- `src/game.js` содержит правила кампании. `src/api.js` выполняет ходы на сервере и защищает состояние номером ревизии.
- `npm run build` создаёт Worker в `dist/server/index.js`. Для запуска на Sites нужна привязка D1 `DB`, миграция из `drizzle/` и штатный вход платформы через ChatGPT. Worker использует идентификатор пользователя из доверенного шлюза. Для переноса на другой хостинг этот шлюз нужно заменить аутентификацией выбранной платформы.
- Локальный запуск использует SQLite и собственные сессии. Локальные логины и сохранения отделены от опубликованной версии.
